# 역행렬 계산 프로그램

이산수학 Report 1. Python 표준 라이브러리만 사용해 행렬식과 가우스–조던 소거법을 직접 구현했습니다.

## 실행

```sh
python3 inverse_matrix.py
python3 inverse_matrix.py --trace
```

양의 정수 n을 입력하고 각 행의 원소 n개를 공백으로 구분해 입력합니다. 정수, 유한소수, 분수를 받을 수 있습니다. `--trace`는 여인수행렬·수반행렬과 확대행렬의 행 연산을 출력합니다.

예시 입력:

```text
2
3 5
2 3
```

예상 역행렬:

```text
-3  5
 2 -3
```

## 구조

- `read_matrix`: 행별 입력 검증 및 2차원 리스트 저장
- `minor`, `determinant`: 소행렬과 첫째 행의 여인수 전개
- `inverse_by_determinant`: 수반행렬을 행렬식으로 나눔
- `inverse_by_gauss_jordan`: 확대행렬의 피벗 탐색·행 교환·정규화·소거
- `multiply`, `identity`: 양방향 단위행렬 검증
- `main`: 두 계산 방법의 독립 실행, 예외 처리와 결과 비교

`Fraction`으로 정확한 유리수 연산을 수행합니다. 특이행렬은 두 함수가 각각 `SingularMatrixError`를 발생시킵니다. 행렬식 계산은 재귀 여인수 전개이므로 큰 행렬에서 느릴 수 있습니다. 가우스–조던의 산술 연산 횟수는 O(n³)이며, 유리수의 실제 비용은 분자·분모 크기에 따라 달라집니다.

## 테스트

수업 예제 2×2 및 3×3, 행 교환 필요 행렬, 특이행렬, 1×1, 잘못된 입력 재입력의 6개 실행을 확인했습니다. 별도로 무작위 2×2 정수행렬 100개를 닫힌 공식과 대조했습니다.

행렬식/역행렬 라이브러리 호출 없이 알고리즘을 직접 구현했습니다.
